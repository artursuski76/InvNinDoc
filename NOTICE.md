Invoice Ninja PL

This repository contains a community-maintained Polish adaptation of the official Invoice Ninja project.

The software provided in this repository is not a standalone application. It is intended to be used together with the official Invoice Ninja Docker image and contains only a limited set of files that customize or extend the upstream application for use in Poland.

Modifications included in this repository

The modifications provided by this project include, among others:

Polish localization improvements,
adjustments for Polish accounting requirements,
support for Polish VAT configuration,
document template customizations,
compatibility with external KSeF integration,
other improvements intended for users operating in Poland.
KSeF integration

Communication with the Polish National e-Invoice System (KSeF) is implemented as a separate application using the public Invoice Ninja API.

The KSeF integration is not part of the original Invoice Ninja project.
